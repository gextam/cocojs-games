One page that launches ten games.

The launch page behind cocojs.com/games: nine play-money casino and board games plus the Agent Arena, each one short link away. A single HTML file with no build step, thumbnails rendered from each game's own screenshots, and a one-line deploy over SSH.

What is inside

Every game is a plain link under /games/; the arena owns the rest of the host. Each game is its own repository and its own static site; this project only arranges them.

How it is served

Everything under /games is plain files in a cPanel account's document root. Apache serves them directly, with directory listings off and media cached for a day. Every other path on the host is reverse-proxied to the arena, a Node service under systemd; the Apache include and the unit file are documented in the arena's README.

Deploying is one command from this folder, with the game folders checked out next to it:

tools/deploy.sh            # page + thumbnails + all nine games
tools/deploy.sh hub        # page + thumbnails only
tools/deploy.sh roulette   # one game
  • tools/thumbs.mjs renders the 800×450 thumbnails from each game's hero screenshot with headless Chrome.
  • tools/screenshot.mjs captures the live page on desktop and phone for the README and this page.
  • Adding a game is a sibling static folder, two map entries, one card. The README has the steps.
